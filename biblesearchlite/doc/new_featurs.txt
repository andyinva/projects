Add new features to bible_search.py
A system to collect, organize, and manage scripture verses from search results into custom subject-based lists with editing capabilities.
User Interface Layout (Top to Bottom)
1. Search Results Section

Search results display box with scripture references
Selection checkboxes on the left side of each verse reference
"Create" button to initiate new subject creation
"Move" button to move selected passages from search results to subject list database

2. Subject Management Bar

Fixed horizontal bar spanning full width below search results
Dropdown menu to select existing subjects or enter/create new subjects
"Move" button to transfer selected verses to chosen subject

3. Navigation and Action Controls

Four navigation buttons (line up/down and page up/down for browsing when not editing)
"Create New Entry" button
"Delete Entry" button
"Edit" button (activates text editor)
"Save" button (appears during editing mode)
"Delete Subject" button (removes entire subject and its verses from database)
"Export" button (saves subject to user's chosen location, defaults to application directory)

4. Subject Verses Display Section

Subject verse display window showing verses for selected subject
Selection checkboxes on left side of each verse reference
Simple text editing capability allowing comments between verse lines
Delete functionality for selected verses via checkboxes

Workflow Process

Search and Select: User searches scripture, checks desired verses
Create/Choose Subject: User creates new subject or selects existing from dropdown
Move Verses: Selected verses transfer to subject database
Manage Lists: Navigate, edit (add comments), and organize subject-based verse collections
Save Changes: Preserve edits and modifications
Export/Delete: Export subjects or remove entire subjects from database

Technical Details

Storage: All data stored in existing SQLite database
Export: Subjects can be exported to user-specified locations with application directory as default

Key Features

Persistent storage of custom scripture subjects in SQLite database
Checkbox-based selection system for both search results and subject lists
In-line text editing with comment insertion capabilities
Full CRUD operations (Create, Read, Update, Delete) for subject management
Subject export functionality for sharing or backup
Complete subject deletion capability
