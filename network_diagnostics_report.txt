ROOT CAUSE ANALYSIS
===================

MOST LIKELY CAUSES (in order of probability):

1. ANTENNA MISALIGNMENT (80% probability)
   - Inverted speed ratio (upload > download) is classic symptom
   - Manufacturer specifically notes alignment affects throughput
   - Even a few degrees off can cause massive speed degradation
   - 5.8GHz requires precise line-of-sight alignment

   FIX: Carefully realign both bridge antennas
        Check signal strength in bridge web interface
        Ensure direct line-of-sight with no obstructions

2. INTERFERENCE ON 5.8GHz (15% probability)
   - Other WiFi networks
   - Wireless cameras
   - Microwave ovens
   - Weather conditions (rain/fog affects 5.8GHz)

   FIX: Check signal quality in bridge interface
        Try different channel
        Check for new interference sources

3. PHYSICAL OBSTRUCTION (3% probability)
   - Trees (especially with leaves)
   - New buildings
   - Distance increased beyond optimal range

   FIX: Clear line-of-sight
        Reduce distance if possible

4. HARDWARE FAILURE (2% probability)
   - One bridge degrading
   - Cable damage
   - Power supply issues

   FIX: Check all cable connections
        Verify power supplies
        Try swapping bridges

2. Check signal strength and quality
   - Signal Strength: Should be better than -70 dBm for good performance
   - Link Quality: Should be >80%
   - Check for high error/retry counts

3. Realign the antennas
   - Start with the bridge closest to you
   - Make small adjustments (1-2 degrees)
   - Monitor signal strength in real-time via web interface
   - Ensure direct line-of-sight
   - Tighten mounting hardware after optimal position found

4. Check for obstructions
   - Verify clear line-of-sight
   - Look for new obstacles (tree growth, construction, etc.)
   - Consider weather conditions

NEXT STEPS IF ALIGNMENT DOESN'T HELP:
1. Check for interference (try different 5.8GHz channel)
2. Verify all cable connections are secure
3. Check power supplies are providing correct voltage
4. Review bridge logs for errors
5. Consider temporary direct connection to router to confirm bridges are issue
