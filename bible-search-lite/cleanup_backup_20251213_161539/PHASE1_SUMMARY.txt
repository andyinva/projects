```
user_data.db                  (NEW - created automatically)
```

Database Schema (user_data.db):
```sql
groups: group_id, group_name (UNIQUE), description, created_date, sort_order
subjects: subject_id, group_id (FK), subject_name, description, created_date, sort_order
  - UNIQUE(group_id, subject_name)
subject_verses: id, subject_id (FK), verse_reference, translation, verse_text, timestamp, sort_order
verse_comments: comment_id, subject_verse_id (FK), comment_text, created_date, modified_date
email_contacts: contact_id, name, email (UNIQUE), notes, created_date
db_version: version, updated_date
```

===============================================================================
TROUBLESHOOTING GUIDE
===============================================================================

DATABASE ERRORS:
- Check user_data.db is in same directory as script
- Verify foreign keys enabled (PRAGMA foreign_keys = ON)
- Check database schema with: sqlite3 user_data.db ".schema"

IMPORT ERRORS:
- Verify services/ directory has __init__.py
- Check Python path includes project root
- Ensure all files have correct module names

UI ERRORS:
- Verify dialogs.py has GroupDialog and SubjectDialog
- Check combo box userData is set correctly
- Confirm signals are connected

ACQUIRE BUTTON NOT HIGHLIGHTING:
- Check update_acquire_button_state() is called
- Verify get_selected_verses() returns list
- Confirm CSS styling is applied
